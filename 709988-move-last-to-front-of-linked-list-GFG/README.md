# [Move Last to Front of Linked List](https://www.geeksforgeeks.org/problems/move-last-element-to-front-of-a-linked-list/1)
## Easy
Given the head of a Linked List, move the last node to the front of the Linked List and return the head the modified linked list.Examples:Input: head: 2-&gt;5-&gt;6-&gt;2-&gt;1
Output: 1-&gt;2-&gt;5-&gt;6-&gt;2Explanation: In the given linked list, the last element is 1, after moving the last element to the front the linked list will be 1-&gt;2-&gt;5-&gt;6-&gt;2Input: head: 2
Output: 2
Explanation: Here 2 is the only element so, the linked list will remain the same.
